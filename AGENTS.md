## Roles especializados

Las definiciones de roles portables viven en `arx/agents/`. No se activan todas
automaticamente: cuando una tarea requiera una especialidad, lee el archivo del
rol indicado y aplicalo durante esa tarea.

Antes de trabajar como un rol especializado:

1. Lee `AGENTS.md`, `README.md` y la documentacion relevante de `docs/`.
2. Lee el archivo especifico dentro de `arx/agents/`.
3. Reporta una seccion `Contexto leido` con los archivos consultados.
4. No combines varios roles salvo que la tarea lo solicite explicitamente.

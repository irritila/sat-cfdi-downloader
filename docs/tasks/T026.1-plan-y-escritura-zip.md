## Criterios de aceptacion

- [x] Dado un perfil con 2 meses indexados de emitidas y recibidas, exportar el rango con Ambas produce un ZIP cuyas entradas son exactamente `emitidas|recibidas/AAAA-MM/<UUID>.xml`, una por CFDI canonico, con SHA-256 identico al XML del paquete fuente; un CFDI presente en dos paquetes aparece una vez. Con Emitidas solo hay entradas `emitidas/`.
- [x] Al planear, una factura elegida que ya no existe (o cuya posicion ahora tiene otro UUID) se omite como "ya no disponible" salvo que su UUID siga disponible desde otra fuente canonica; un paquete `OrigenNoDisponible` o `Ilegible` ya no conserva filas y su mes aparece como "cobertura incompleta" (ADR 0023); un mes con descargas pendientes produce su linea; `formatearOmitidas` coincide byte a byte con el texto esperado (D17) y sin lineas no hay archivo; el numero de lineas de CFDI con motivo distinto de "sin PDF" es el de omisiones. Cada factura planeada lleva la huella del paquete fuente para que T026.2 revalide. Las omisiones de lectura (desaparece, otro UUID, ilegible) son de T026.2.
- [x] El asignador produce `sin-uuid-<n>` para UUID vacio o no canonico y `-<n>` en colisiones, igual para XML y PDF; ninguna entrada contiene nombres internos de paquetes, `..`, rutas absolutas ni enlaces. La inspeccion del ZIP muestra comentario vacio, atributos `0100600` y fecha de la exportacion.
- [x] Con fallas inyectadas en crear, escribir, cerrar, `F_FULLFSYNC`, rename y disco lleno, o cancelacion en cada fase previa al rename: no hay ZIP final, el `.partial` propio se borra y un archivo previo con ese nombre queda intacto. Con falla solo en el `fsync` del directorio tras el rename, el ZIP queda publicado y el resultado trae advertencia. Durante y despues de exportar, en la carpeta privada y en la destino no hay otros archivos que el `.partial` propio y el ZIP final. El ZIP final tiene `0600` (`stat`), sin ACL y sin atributos extendidos salvo `com.apple.provenance`, que macOS asigna y no se puede retirar.
- [x] Un destino existente no se reemplaza, tampoco si aparece entre el dialogo y el rename; se pide otro nombre. El nombre se sanea segun D15 (vacio, sin extension, doble extension, `/`, `:`, inicio con `.`, mas de 255 bytes).
- [x] Si el proceso termina durante la exportacion (simulado dejando un `.partial` propio), el siguiente arranque lo borra; un archivo ajeno, un enlace o un nombre que no sigue el patron permanecen.
- [x] Con datos sonda (`XAXX010101000`, un UUID sintetico, `/Users/usuario`, un nombre de archivo hostil) los logs y notificaciones capturados no contienen ninguno; solo fases, conteos y codigos.
- [x] ADR registrado y `docs/architecture.md` actualizado (`docs/requirements.md` y el manual van en T026.3).
- [x] Build `-Werror`, `ctest` y `git diff --check` pasan.

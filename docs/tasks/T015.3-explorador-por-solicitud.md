# T015.3: Explorador de CFDI por solicitud

## Estado

Pendiente (refinada 2026-10-11).

## Objetivo

Desde el detalle de una solicitud, ver la lista de sus CFDI con busqueda y estados claros.

## Decisiones

T015 D1, D10. Estilo de T013 (`Theme`, componentes existentes).

## Alcance

### Incluye

- Accion "Ver facturas (N)" en el detalle de una solicitud con paquetes descargados, que abre el explorador de esa solicitud.
- Lista con fecha, tipo, serie-folio, emisor (RFC y nombre), receptor (RFC y nombre), total y moneda, metodo de pago, UUID abreviado (copiable) y estado de parseo; orden por fecha; busqueda por RFC, nombre, UUID o folio; filtro por tipo de comprobante.
- Estados: la lista muestra siempre los CFDI ya indexados. Encima, una linea por condicion con conteo, en este orden: indexando N paquetes, N paquetes no disponibles (ZIP faltante), N paquetes ilegibles, N CFDI ilegibles o no soportados. El estado vacio ("Sin facturas") solo aparece con cero CFDI y nada indexandose; un error de lectura del indice reemplaza la lista con "No se pudo leer" y "Reintentar".
- Busqueda: sin distinguir mayusculas ni acentos; RFC, nombre y folio por subcadena; UUID completo o parcial.
- Seleccionar un CFDI abre su previsualizacion (T015.4).

### No incluye

- Vista global, exportacion.

## Dependencias

- T015.2. T013.

## Criterios de aceptacion

- [ ] Dada una solicitud con paquetes indexados, cuando se abre "Ver facturas", entonces la lista muestra todos sus CFDI con las columnas indicadas y el conteo coincide con el indice.
- [ ] Cuando se busca por RFC, nombre, UUID o folio, o se filtra por tipo, entonces la lista se reduce a las coincidencias; sin coincidencias hay un estado vacio con "Limpiar filtros".
- [ ] Dada una solicitud aun indexandose, con ZIP faltantes o con CFDI ilegibles, entonces se ve el estado correspondiente sin error modal y con la accion de T009.1 para revisar la carpeta.
- [ ] Una solicitud sin paquetes descargados no ofrece "Ver facturas".
- [ ] Con teclado: Tab recorre busqueda, filtro y lista; flechas mueven la seleccion; Enter abre la previsualizacion. Cada fila tiene nombre accesible "tipo, fecha, emisor, total". Se ve bien en claro y oscuro; capturas del manual actualizadas con datos sinteticos (T012).
- [ ] Prueba manual del usuario con una solicitud real: 3 CFDI comparados con su XML (UUID, RFC emisor, total), evidencia "coinciden N de 3".
- [ ] `ctest` pasa completo.
